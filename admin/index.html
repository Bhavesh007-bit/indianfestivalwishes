GitHub token daalo aur ek password banao. Token is device par password se lock hokar rahega.

Token kaise banaye, ye neeche "Token kaise banaye" me likha hai.
Purane panel ka token mil gaya hai aur neeche bhar diya gaya hai. Bas ek password bana ke setup poora karo.
Token kaise banaye
  1. GitHub > profile photo > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Naam site-admin, expiration 90 days.
  3. Repository access: Only select repositories > indianfestivalwishes.
  4. Permissions > Repository > Contents: Read and write.
  5. Token copy karke upar wale box me daalo.
