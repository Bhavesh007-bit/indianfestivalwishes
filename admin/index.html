⚙ Admin Panel: Indian Festival Wishes

Site kholo ↗

1. GitHub se jodo

Admin panel aapki GitHub repository me static/site-settings.json file badalta hai. Iske liye ek baar GitHub "token" banana hoga.

Token kaise banaye (ek baar ka kaam)
  1. GitHub par: profile photo > Settings > sabse neeche Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Naam: site-admin. Expiration: 90 days (khatam hone par naya bana lena).
  3. Repository access: Only select repositories > indianfestivalwishes.
  4. Permissions > Repository permissions > Contents: Read and write. Baaki kuch mat chhedna.
  5. Generate token dabao aur token copy karke neeche daalo. Ye token kisi ko mat dena.

2. Affiliate products

Amazon Associates ka tracking ID daalo (jaise yourname-21). "Search shabd" wale products apne-aap Amazon search link ban jaate hain aur unme aapka ID lag jaata hai. Kisi product ka seedha link ho to "Direct link" me daalo. Bina tracking ID aur bina direct link wale products site par nahi dikhte.

3. Telegram channel promotion

Link https://t.me/ se shuru hona chahiye. Page ke beech me ek box aur neeche chipki hui patti dikhegi (user band kar sakta hai).

4. Announcement patti

Har page ke upar ek chhoti patti, jaise "Diwali sale shuru!" ya "Naye Dussehra cards aa gaye". Link optional hai.

5. Google AdSense aur Analytics

AdSense approve hone ke baad yahan ID daalo. Slot ID AdSense me "Ads > By ad unit" se milta hai. Sirf Auto ads chahiye to slot khali chhod do.

Dhyan do: AdSense site verify karte waqt jo code maangta hai, wo seedha HTML me hona chahiye. Uske liye Claude se nayi files banwa lena, ya AdSense me "ads.txt" wala tareeka chuno.
